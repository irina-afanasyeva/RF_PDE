# Meeting 10 — 2026-10-28

## Context

Following the self-adaptive PINN direction from the 2026-10-21 meeting
(`docs/meetings/2026-10-21.md`; `RESEARCH_LOG.md` Section 40), the paper
was identified (McClenny & Braga-Neto, arXiv:2009.04544), a from-scratch
PyTorch SA-PINN implementation was built (`Burgers/sapinn/`), and a
10-seed campaign across five weighting configurations was run and
audited. In parallel, a narrow RF-only optimization experiment (L-BFGS
refinement vs. continued Adam) was completed. See `RESEARCH_LOG.md`
Sections 41–42 for the full numerical record; this note covers only what
was presented and decided.

## Work presented

- SA-PINN Burgers implementation and reproduction, verified against the
  official reference code and the paper text, with every numeric choice
  tagged by provenance (`sapinn/config.py`).
- Ten-seed comparison of five weighting configurations (`baseline`,
  `fixed_weight`, `adaptive`, `balanced_10`, `balanced_100`).
- Adaptive SA-PINN mean global relative L2 error ≈ 9.765e-4 (10 seeded
  runs) versus the paper's published 4.80e-4 (10 unseeded restarts) — same
  order of magnitude, not claimed as a reproduction given disclosed
  dtype/sampling/`N_b` differences.
- Both balanced fixed-weight configurations (`balanced_10`, `balanced_100`)
  achieved lower average global and shock-region error than `adaptive` in
  this campaign.
- The strongly unbalanced `fixed_weight` configuration (col=100,
  u~Uniform(0,1), frozen) is numerically unstable: 7 of 10 seeds fail (6
  NaN, 1 undetected finite divergence), versus zero failures across all 40
  seeds of the other four modes.

## Professors' feedback

**Confirmed decisions** (direct requests from this meeting):

1. Investigate whether self-adaptive weighting improves the RF solver
   (SA-RF).
2. Match the number of trainable parameters between SA-PINN and SA-RF.
3. Revisit the SA-PINN experimental settings to track the published
   paper more closely.
4. Specifically: change boundary collocation from 50 total (25 per side,
   the reference code's value) to 200 total (the paper's stated `N_b`,
   Section 4.1 — see `RESEARCH_LOG.md` Section 41 for the documented
   code-vs-paper discrepancy this resolves).

**Flagged for clarification, not yet a confirmed requirement:**

Item 2 ("match trainable parameters") is ambiguous given SA-PINN's actual
parameter structure (`RESEARCH_LOG.md` Section 41): 3,021 network
parameters plus 10,100 self-adaptive attention parameters (one per PDE
collocation point + one per IC point), for 13,121 total during Adam. It
was **not confirmed at this meeting** whether "match parameter count"
means (a) match only the 3,021 network/function-approximator parameters
(our working interpretation, since the RF model's trainable coefficients
are the direct analog of the PINN's network weights, while attention
weights play a structurally different role and would need a separate
RF-side counterpart), or (b) match the full 13,121 including attention.
**This distinction should be confirmed with the professors before it is
treated as a finalized experimental requirement** — see `TODO.md`.

## Proposed next steps (not yet completed)

- Develop SA-RF: add pointwise self-adaptive weights to the PDE and IC
  terms of the RF loss, with gradient-ascent updates analogous to
  SA-PINN's `adaptive` mode.
- Under interpretation (a) above: match SA-PINN's 3,021 network
  parameters with 3,021 trainable RF coefficients (e.g. a different
  `Nx*Nt` factorization than the canonical 500×10=5,000), while separately
  accounting for — not necessarily matching — the 10,100 attention
  parameters, since they are not part of the function approximator itself.
  **Not yet implemented; interpretation pending confirmation (see above).**
- Use a controlled fixed-weight RF baseline (frozen weights, analogous to
  SA-PINN's `fixed_weight`/`balanced_*` controls) to separate "adaptive"
  from "frozen-but-reweighted" effects, following the same logic that
  motivated `balanced_10`/`balanced_100` for SA-PINN.
- Re-run the SA-PINN campaign with 200 total boundary points (100 per
  side) instead of 50, to track the published paper's stated setting more
  closely.
- Compare global relative L2 error, shock-region error, training
  stability, and computational cost across RF-baseline, SA-RF, and the
  existing SA-PINN modes.
