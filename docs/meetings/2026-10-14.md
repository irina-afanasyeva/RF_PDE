# Meeting 08 — 2026-10-14

## Context

Following the RF basis-size sweep, the Nx=1000 longer-training diagnostic,
the frozen-RF K=8 Gaussian PDE-training experiment, and the first two
multiscale RF experiments (see `RESEARCH_LOG.md` Sections 31–34).

## Work presented

- RF basis-size sweep: under the fixed canonical 1000-epoch training
  budget (seed=42, Nt=10), solution error (global/smooth/shock) increased
  as Nx grew from 500 to 1000 to 2000, even though the sampled PDE loss
  decreased.
- Nx=1000 longer-training diagnostic: continuing the same Nx=1000 model to
  10,000 epochs gave only modest improvement and still did not match the
  canonical Nx=500 result at 1,000 epochs.
- Frozen-RF K=8 Gaussian PDE training: with the canonical Nx=500 RF
  completely frozen and the K=8 post-hoc capacity-study geometry fixed,
  PDE training activated the 8 local amplitudes only weakly relative to
  the strong post-hoc/oracle capacity of the same basis.
- Two-population multiscale RF: an aggressive high-frequency population
  (std=312.5 alongside the canonical std=25) substantially worsened both
  solution accuracy and PDE loss; a moderate high-frequency population
  (std=75) gave the first controlled positive multiscale result,
  improving global, smooth, shock, and PDE metrics simultaneously at the
  same total Nx=500.

## Discussion / advisor input

- **Main message: the baseline `u_RF` needs to work well before local
  shock enrichment is the primary focus.** The advisor's central
  assessment is that the current `u_RF` is not sufficiently accurate — he
  expects a well-constructed RF approximation to reproduce the smooth
  portions of the Burgers solution well, with the principal difficulty
  concentrated near the shock, and reports that his own RF solution
  already achieves this more successfully than the current implementation.
- The RF basis-size sweep is not yet sufficient to establish genuine
  convergence behavior: only one random seed was used, and Nt was held
  fixed while only Nx varied. Suggested: run multiple seeds; study Nx and
  Nt jointly, possibly with a controlled Nx/Nt ratio; broaden the RF-size
  range investigated. The exact grid was left open.
- Suggested trying a smaller learning rate as a controlled diagnostic of
  `u_RF` quality, kept separate from other architecture changes so its
  effect can be isolated.
- On multiscale RF: continue the investigation, but select sigma1/sigma2
  more systematically — ideally informed by PDE structure rather than
  chosen arbitrarily — and also investigate the N1/N2 allocation between
  populations and the effect of increasing total N. Explicitly cautioned
  against treating the successful std=75 result as having found the
  correct or optimal scales.
- Proposed testing an alternative joint space-time RF formulation
  (`cos(wx*x + wt*t + b)`, treating (x,t) as one joint input) as an
  untested idea, to compare against the current separable product
  features (`cos(wx*x+bx)*cos(wt*t+bt)`). Noted that a fair coefficient
  budget between the two representations is not automatic and still needs
  to be decided.
- Clarified a correctness point about the local Gaussian correction:
  `u_local(x,t) = t*sum_k d_k G_k(x)` satisfies the initial condition
  exactly (`u_local(x,0)=0`), but does not analytically satisfy the
  Burgers boundary condition at `x=±1` — for narrow Gaussians centered
  near the shock this is numerically negligible but not exact by
  construction.
- Explicitly directed that making the local Gaussian's center, width, and
  amplitude jointly trainable should be **postponed**, not pursued next —
  the immediate priority is improving the RF baseline itself.
- Asked that the `burgers-local-features` GitHub branch be shared so
  implementations can be compared directly.
