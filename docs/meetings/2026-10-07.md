## Work presented

- **Representation.** The actual PDE-trained RF residual at `t=1` is
  strongly localized and sign-changing near the shock. One shifted
  Gaussian substantially improves the shock residual; a jointly searched
  two-Gaussian opposite-sign pair represents it extremely well (~99.8% of
  the shock residual's variance); greedy K-Gaussian enrichment through
  `K=8` demonstrates substantial additional representation capacity.
  `K=8` was presented explicitly as a representation-capacity diagnostic,
  not a globally optimized 8-Gaussian solution.
- **Training.** With the canonical RF frozen, PDE training moves the
  two-Gaussian amplitudes initially in the same signs as the `t=1` oracle
  amplitudes. `weight_decay=1` strongly suppresses the local correction;
  reducing/removing weight decay improves the learned correction
  (especially the second Gaussian) but does not recover the `t=1` oracle
  amplitudes. Representation is therefore not the main limitation;
  regularization contributes to amplitude suppression, but a large
  discrepancy remains between the multi-time PDE-training objective and
  the `t=1` solution-error oracle.

## Discussion / advisor input

- **RF basis-size study.** Advisor asked to test the number of random
  spatial features: handwritten values `N = 500 -> 1000 -> 2000`. Compare
  results and produce an error-vs-`N` plot, tracking both global relative
  error and shock-region relative error. Purpose: determine whether
  increasing RF capacity continues to reduce error, or whether it
  plateaus.
- **Extend Gaussian enrichment to larger K.** Advisor wrote to try `K=8`
  or more, for both groups of experiments discussed at the meeting: (1)
  the post-hoc/oracle representation diagnostics, and (2) the
  PDE-training diagnostics. Also investigate this together with the RF
  basis-size study above. **The exact N-by-K combinations to run are not
  yet decided** — recorded as TBD/needs confirmation with the advisor, not
  a full N×K matrix to run blindly.
- **Trainable Gaussian geometry.** Move beyond fixed `(center, width)`
  Gaussian geometry: train center `c`, width `sigma`, and amplitude `d`
  jointly through the PDE objective. For multiple Gaussians this
  generalizes to `{c_k, sigma_k, d_k}`. Recorded as a future experiment,
  not yet attempted.
- **Reporting convention.** Advisor asked that global relative L2 error
  and shock-region relative L2 error both be consistently reported and
  included in all experiment comparisons/plots going forward (already the
  convention in most of this study; reaffirmed explicitly here).
- **Multiscale RF basis — new hypothesis.** Advisor raised changing the
  spatial RF construction so the basis contains two populations with
  different frequency scales:

  ```
  u_RF = sum_{k=1}^{N1} a_k cos(w_k^(1) x + b_k^(1))
       + sum_{k=1}^{N2} beta_k cos(w_k^(2) x + b_k^(2))

  w_k^(1) ~ N(0, sigma_1^2),  w_k^(2) ~ N(0, sigma_2^2),  N = N1 + N2
  ```

  Motivation/hypothesis: one population may represent smoother spatial
  structure while the other (different frequency scale) may provide
  additional resolution around the sharp shock. **This is a
  hypothesis/new direction, not an established conclusion.** The
  handwritten notes appear to contain candidate `N1,N2` values, but their
  precise interpretation is not settled — marked TBD/confirm with advisor
  rather than inventing specific values here.
